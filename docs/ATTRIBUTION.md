## If you use EPDS privately

You may use, modify, and adapt EPDS in private projects. Keeping the source notice is recommended for traceability.

## If you redistribute EPDS or a derivative

You must comply with Apache License 2.0, including:

1. Include a copy of `LICENSE`.
2. Retain applicable copyright, patent, trademark, and attribution notices.
3. Retain the notices in `NOTICE` in a readable form.
4. Mark modified files prominently to state that you changed them.
