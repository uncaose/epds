# Code references the specification

Write code comments that point to the specification document the code implements, so a reader can trace each behavior back to its requirement.

**Why**: Code that carries only its own explanation drifts from the requirement it serves; a pointer to the spec lets a reader, a reviewer and a later change check the code against the source of truth instead of guessing the intent.
