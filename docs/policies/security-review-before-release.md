# Security review before release

Run a security review (vulnerabilities and personal data) before release, in the release or verify step, and record its result as release evidence.

**Why**: Functional checks do not look for exploitable flaws or leaked personal data; one review at the last gate catches what feature tests are not written to see, and a recorded result lets the release decision cite it.
