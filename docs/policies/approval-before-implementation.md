# Approval before implementation

Do not implement strategic, exploratory, or sensitive work before the user approves the decision and scope.

**Why**: STRATEGIC/SENSITIVE work is expensive or hard to reverse; the owner's call, not the agent's, decides whether to spend the effort at all (see `docs/ROLES.md` classification→role table).
