# Irreversible actions need confirmation

Do not send communications, make purchases, change permissions, delete data, or deploy to production without explicit confirmation and a rollback plan where applicable.

**Why**: These actions are hard or impossible to undo; an agent proceeding on an assumption instead of a confirmation risks real-world, not just in-repo, damage.
