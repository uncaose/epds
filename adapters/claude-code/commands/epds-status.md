Use the installed `epds` skill and execute the `status` procedure.

Do not modify project files. Read available evidence first; research trusted public sources only when material facts are missing; ask only owner-only questions.

When the bottleneck is a specific perspective (agent-ops, cost, evidence, safety, delivery, ...), check `epds/trusted-sources.json` first: list up to 3 entries whose `perspectives` or `patterns` match, and present them as leads (id, url, purpose) before researching further.
